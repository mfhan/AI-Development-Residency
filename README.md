## 🔁 How I work

Each assignment or challenge follows the same loop:

1. `git pull origin main` — start from the latest.
2. `git checkout -b assignment-NN-short-name` — a new branch per task.
3. Work in small, clearly-messaged commits.
4. `git push -u origin assignment-NN-short-name` — push the branch.
5. Open a **Pull Request** — this is the submission.
6. Address feedback, merge, delete the branch, repeat.
